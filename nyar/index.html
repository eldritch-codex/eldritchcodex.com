Nyar

A real-time renderer for Nodens, built on the Vulkan graphics API as a learning exercise. It starts from the Khronos "Drawing a triangle" tutorial and grows, step by step, into a clean rendering API for Nodens applications.

Stack: C++ Vulkan Slang Nodens
Links
  • Repository
  • Milestones
  • 01 · What

    A renderer for Nodens

    Nyar is the part of Nodens that draws. It is a separate module, so Nodens applications can use it as their rendering backend.

  • 02 · Why

    A learning exercise

    Nyar exists to understand modern real-time rendering by building it, one small working step at a time.

  • 03 · How

    Vulkan and Slang

    It uses current Vulkan, and shaders written in Slang, a modern shading language.

hello-triangle · the first milestone

Where it is today

Nyar is at the start of its path. What runs today is the Khronos Drawing a triangle tutorial, adapted to run inside a Nodens application. It is a known-good baseline, not yet the renderer.

Where it is going

The plan, in order. Progress is tracked in the milestones.

  • 01 · Now

    Finish the tutorial

    Get the whole Khronos tutorial running inside a Nodens application.

  • 02 · Next

    Refactor into an API

    Reshape that working code, step by step, into a dedicated renderer with a clear public interface.

  • 03 · Then

    Used by Nodens apps

    Nodens applications import Nyar and draw their scenes through it, while Nodens keeps the window and the frame loop.

Follow along

Linux is the supported setup for now.
