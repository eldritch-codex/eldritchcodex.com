Armitage

Armitage is an agent toolkit (CLI, skillset and a custom Pi harness). The model answers from three sources you choose: your Zotero library, a Markdown memory and your workspace code. The role you pick sets the workflow: SWE (coder, architect, devops, debug), Tutor or Researcher. Every answer cites its sources, with links that open the Zotero item or the code file at the right page or line.

I built Armitage mostly with AI coding agents, to help me develop Nodens and Nyar. It is a personal, experimental project, and agent tooling is outside my area of expertise.

Stack: Python Pi Zed ACP ChromaDB Ollama Zotero Obsidian

What makes it different

Six things Armitage does that a plain coding agent does not.

  • 01Verified

    Citations that are checked

    Each reference must resolve to a real file and line, or a real Zotero page, and must have been looked up this session. A source the model only remembers is refused.

  • 02Stored

    Memory that quotes the source

    Findings are stored as the source's own words, linked to the exact page. The quote is checked against the file, even with Zotero closed.

  • 03Local

    Search that stays on your machine

    Embeddings, keyword search and reranking all run locally, light enough for a modest GPU.

  • 04Approved

    Studies you approve

    A research plan waits for your approval. A report is refused unless every analysis paragraph cites a page or says Inference.

  • 05Planned

    Designs you approve

    Before a big code change it writes a design and asks its open questions. The plan cannot be approved with one unanswered, and it is then built one phase at a time: you commit each, and every turn names the next role.

  • 06Remembered

    Decisions it remembers

    When you settle something, Armitage records it in your words and loads it into every later session.

Built around Zotero, Zed and Pi

Three native integrations. Zed and the terminal both run on Pi.

  • Pi

    The agent harness and terminal UI

    Armitage is built on Pi. armitage agent pi opens Pi with Armitage's own interface: a header board, a status footer and a plan docked above the input. Tool calls fold to one row, ctrl+o expands them, and /prefs changes the role and settings.

  • Zotero

    Your library is the source

    Armitage reads Zotero 7+ through its local API and never writes to it. It reads PDFs page by page (with OCR for scans), EPUBs by chapter and saved web pages by section. Every citation opens at the exact page or passage.

  • Zed

    Native in the Agent Panel

    A custom ACP adapter on top of Pi runs the same agent, roles and gate as the terminal. Questions and approvals appear as native cards, and a code citation opens the file at the cited line.

Ways to use it

Armitage has three parts: a CLI that manages memory, Zotero, code search, plans and GitHub issues; a skillset that sets the persona and the workflows; and a custom harness built on Pi, with its own terminal UI and an ACP adapter for Zed. Skills and the CLI are the portable base. The best way is Zed, through Pi and ACP; the terminal interface on Pi is the alternative.

Skills & CLI · core, no Pi or Zed required

Instructions for your coding agent, plus a CLI for memory, code and Zotero search. The CLI works on its own; the agent is a second package that adds Pi, the skills and ask under armitage agent.

How a question is answered

                    
One search across memory, code and papers, then four steps to an answer with a source for every
                        claim.

                

                

                    
    
                        
  1. 1
                            
    
                                
    Ask: One question
    
                                
    A single query searches memory, papers and code at once (armitage search).
    
                            
    
                        
    2. 
                        
  2. 
                            
      
                                
    • 
                                    Memory
                                    
      The agent's notes, kept as Markdown in an Obsidian vault.
      
                                
      • 
                                
    • 
                                    Papers, books & web
                                    
      Your read-only Zotero 7+ library: PDFs, EPUBs and saved web pages.
      
                                
      • 
                                
    • 
                                    Code
                                    
      An index of your repositories. Symbol lookups need no AI model.
      
                                
      • 
                            
    
                        
    3. 
                        
  3. 2
                            
    
                                
    Match: Meaning + keywords
    
                                
    Embedding search (Ollama) finds passages by meaning; SQLite full-text search finds exact words.
    
                            
    
                        
    4. 
                        
  4. 3
                            
    
                                
    Rank: Best passages first
    
                                
    Matches from all sources are merged, then a reranking model (Qwen3) puts the most relevant first.
    
                            
    
                        
    5. 
                        
  5. 4
                            
    
                                
    Cite: Every claim sourced
    
                                
    Each factual statement carries an inline [^n] footnote to its source.
    
                            
    
                        
    6. 
                    

                

            


            

                

                    
How a claim earns its source

                    
What happens between your question and a cited answer.

                

                

                    
    
                        
  1. 1
                            
    
                                
    Sweep
    
                                
    On your first fact-bearing question, it recalls related memory, plans, code or literature in about three seconds.
    
                            
    
                        
    2. 
                        
  2. 2
                            
    
                                
    Look up
    
                                
    The agent reads the code or queries Zotero, so claims rest on sources, not on what the model remembers.
    
                            
    
                        
    3. 
                        
  3. 3
                            
    
                                
    Answer
    
                                
    Factual answers use a form with claims and their references, not free prose.
    
                            
    
                        
    4. 
                        
  4. 4
                            
    
                                
    Audit
    
                                
    Each footnote is checked: the file and line exist and were read, or the Zotero item was returned this session and the page exists.
    
                            
    
                        
    5. 
                        
  5. 5
                            
    
                                
    Correct
    
                                
    A failed check sends the agent back, up to three times. If it still fails, the answer is flagged with a visible warning.

Roles

                    
Each role loads the skills it needs and adds a workflow drawn from the literature, cited by
                        page. It also sets what Armitage may touch. Pick one with /role; only you can
                        switch it. Pick the role for the kind of work and its skills come with it. Every other
                        skill stays available in every role: the model loads it when the task matches, and you can
                        also type it by name. Outside Pi there are no roles, only skills.

                

                

                    
Can edit your files

                    
    
                        
  • Default
                            
    
                                
    auto
    
                                
    Reads your request and chooses how to work: answer, investigate, plan, implement or teach.
    
                            
    
                        
    • 
                        
  • Builder
                            
    
                                
    swe-coder
    
                                
    Builds one phase of an approved plan, proves it with tests and its docs, then stops so you can commit it. Never commits itself. Skills: armitage-swe, work-patterns.
    
                            
    
                        
    • 
                        
  • Delivery
                            
    
                                
    swe-devops
    
                                
    Handles CI/CD, releases, versioning and git, and groups the phase commits before a push. Writes no application code, and confirms before any commit, push, tag or deploy. Skills: armitage-maintain, work-patterns.
    
                            
    
                        
    • 
                    

                    
Read-only: cannot change your files

                    
    
                        
  • Quick questions
                            
    
                                
    ask
    
                                
    Short, cited answers from Zotero and memory. armitage agent ask locks this role.
    
                            
    
                        
    • 
                        
  • Research
                            
    
                                
    researcher
    
                                
    Plans a study from your Zotero library, waits for approval, then reports with the exact page behind each claim. Skills: armitage-research.
    
                            
    
                        
    • 
                        
  • Teaching
                            
    
                                
    tutor
    
                                
    Teaches a concept or guides an implementation so you can do it alone. Never writes your code. Skills: armitage-tutor.
    
                            
    
                        
    • 
                        
  • Design
                            
    
                                
    swe-architect
    
                                
    Designs a feature, then reviews each finished phase against the plan: on plan, fixable, or the plan is wrong. Names the trade-offs. Skills: armitage-swe, work-patterns, caveman-review.
    
                            
    
                        
    • 
                        
  • Diagnosis
                            
    
                                
    swe-debug
    
                                
    Finds why something fails before any edit and hands you an evidence-backed cause. Skills: work-patterns.

Staying in control

                    
The agent has a shell and your notes, so it is contained in layers. The sandbox is not perfect
                        isolation; the project documents its known limits.

                

                

                    
Contains the agent

                    
    
                        
  • Shell
                            
    
                                
    Sandboxed commands
    
                                
    Runs in bubblewrap with no network and SSH, AWS and GPG folders hidden. Without the sandbox, the shell refuses to run.
    
                            
    
                        
    • 
                        
  • Files
                            
    
                                
    File-tool guard
    
                                
    Writes outside the workspace are refused, and reads outside it ask you first.
    
                            
    
                        
    • 
                        
  • Rules
                            
    
                                
    Protected rules
    
                                
    Skills, persona and your profile are read-only to the agent, so it cannot widen its own sandbox.
    
                            
    
                        
    • 
                        
  • Models
                            
    
                                
    Local search, your choice of chat model
    
                                
    Embeddings and reranking run on a local Ollama, and the CLI refuses a remote Ollama host unless you opt in, so your library is never sent to a search service. The chat model is separate: Pi uses whichever provider you configure, hosted or local. Passages the agent reads are sent to that provider like any other prompt.
    
                            
    
                        
    • 
                    

                    
Keeps you in charge

                    
    
                        
  • Commands
                            
    
                                
    Permission prompts
    
                                
    Commands ask before running: all, only risky ones, or none, with per-command allow and deny rules. The TUI footer always shows the current level.
    
                            
    
                        
    • 
                        
  • Roles
                            
    
                                
    Read-only roles
    
                                
    The researcher, tutor, architect and debug roles cannot change your files. Their builds and tests run in a throwaway overlay.
    
                            
    
                        
    • 
                        
  • Library
                            
    
                                
    Zotero untouched
    
                                
    Armitage never writes to Zotero. The one opt-in OCR option rewrites a PDF and keeps the original.
    
                            
    
                        
    • 
                        
  • GitHub
                            
    
                                
    Its own GitHub login, optional
    
                                
    Issues change only after you approve each one, through a login kept apart from your own gh login. With a bot account, agent-written issues are recognisable on GitHub, at the cost of a second account to set up and secure. With a scoped token of your own account, setup is lighter, but the issues appear under your name. Without a login, the agent writes the text and you file it.
    
                            
    
                        
    • 
                    

                

            


            

                

                    
Where it is going

                    
Planned, not built yet. The core stays small and other tools plug into it as plugins.

                

                

                    
    
                        
  • Tools
                            
    
                                
    Standalone, in any language
    
                                
    A tool is its own app with its own repository and CLI. Tools talk to Armitage only through that CLI and JSON, and none imports another.
    
                            
    
                        
    • 
                        
  • Plugins
                            
    
                                
    A manifest, not code
    
                                
    A tool prints a manifest of the commands the agent may call, and Armitage turns each into an agent tool. A plugin needs no TypeScript and no change to Armitage.
    
                            
    
                        
    • 
                        
  • Reach
                            
    
                                
    Opt-in, and you confirm writes
    
                                
    Each plugin declares how far the agent may go: none, status, read or write. Armitage enforces it, and every action that changes something waits for your confirmation outside the model.

The skills

                    
Instructions the agent follows, which the roles build on. They are grouped by who can start them. A
                        role loads the skills it needs for you, so you start a skill by hand only when no role
                        covers it.

                

                

                    
Only you start these

                    
The agent cannot start these. The researcher and tutor roles load theirs for you.

                    

                        
                            

                                armitage-research
                                Plans the research, waits for your approval, reads each source, and reports with the exact Zotero page behind every finding.
                            

                            

                                armitage-tutor
                                Teaches you step by step instead of just writing the answer, grounded in your code, notes and papers.
                            

                        
                    

                    
You or the agent

                    
Type them by name, or the agent loads them when the task matches.

                    

                        
                            

                                armitage-init
                                Starts or resumes a session: recalls prior work, attaches the right project and plan, then routes to the next skill.
                            

                            

                                armitage-project
                                Keeps a project file for a bigger goal: aims, ideas, open questions, decisions and its plans.
                            

                            

                                armitage-plan
                                Keeps a plan for one piece of work, with checkpoints so a later session can pick up where you left off.
                            

                            

                                armitage-consolidate
                                Turns an approved research report into linked memory notes and an Obsidian canvas.
                            

                            

                                armitage-maintain
                                Advice on versioning, git workflow, changelogs, releases and roadmaps, based on the repository's real state.
                            

                            

                                armitage-help
                                Shows the quick-reference card for all the skills.
                            

                        
                    

                    
The agent starts these

                    
The agent loads them when the task matches.

                    

                        
                            

                                armitage
                                The citation gate. Searches memory, code and papers before a factual answer and cites every claim. An unsourced claim is cut or marked unverified.
                            

                            

                                armitage-swe
                                Before a big change (over 3 files or 80 lines, a new feature, a migration), writes a design plan and implements only after you approve.
                            

                            

                                armitage-github
                                Writes, searches and triages GitHub issues through the agent's own login. Nothing is sent until you approve.
                            

                            

                                armitage-learn
                                Saves findings as citation-backed notes so later sessions can recall them.
                            

                            

                                armitage-decide
                                Records what you settle ("never X", "keep Y") with the reason and your words, so no later session proposes the opposite.
                            

                            

                                armitage-user
                                Maintains your profile: preferences, corrections, goals and deadlines.
                            

                            

                                armitage-obsidian
                                Formats notes for Obsidian and builds tables, boards and canvas maps of the memory on request.
                            

                        
                    

                    

                        Also bundled from the Caveman project (MIT), outside the citation system:
                        work-patterns (working habits such as investigate-first and surgical-patch),
                        caveman, caveman-commit and caveman-review.
