I C++23 · Linux · Static library experimental

Nodens

An experimental C++23 framework for building interactive desktop applications quickly, with an optional immediate-mode GUI (Dear ImGui). Everything is exposed as C++ modules, so an app starts with import nodens;, and the framework links as a single static library.

Links
  • Repository
  • Wiki
  • App template
01 · Windowing

GLFW windows

Creates the window, graphics context and input handling, with OpenGL or Vulkan backends.

02 · Lifetime

Layer system

An app is a stack of layers. They update in order, draw back to front, and receive input from the top down.

03 · Messaging

Event system

Input events pass down the layers. A thread-safe event bus lets any part of the app publish and subscribe to custom events, handled immediately or queued.

04 · Concurrency

Job system

Runs heavy work, like simulation and data processing, on worker threads so the render thread stays responsive.

Writing an app

  • An app inherits from Nodens::Application, pushes one or more layers, and calls Run(). Every frame, each layer receives OnEvent, OnUpdate(TimeStep) and OnImGuiRender(TimeStep).
  • Two examples ship with it: circularwave3d (live 2D/3D plots with ImPlot and ImPlot3D) and planetaryscan (the event bus and job system working together).
  • Tracy profiling is built in: add ZoneScoped inside any layer method to see it in the profiler.
  • CMake downloads and builds every dependency from source, so there is nothing to install by hand.

II Vulkan 1.3 · Slang · C++23 experimental

Nyar

A Vulkan 1.3 real-time renderer built as a separate module for Nodens, and a learning exercise in modern graphics APIs. It starts from the official Khronos "Drawing a triangle" tutorial and is refactored step by step into a clean rendering API.

Links
  • Repository
  • Milestones
01 · Shaders

Slang to SPIR-V

Shaders are written in Slang, a shading language, and compiled to SPIR-V (the format Vulkan loads) by a custom CMake target.

02 · Pipeline

Modern Vulkan 1.3

Uses Vulkan's current features: dynamic rendering (no render pass objects), synchronization2 and extended dynamic state.

03 · Direction

Nodens integration

Packaged as a C++ module (export module nyar;) that Nodens applications import as their rendering backend.

III Python 3.14 · Zotero · Obsidian private preview

Armitage

Armitage helps an AI coding agent answer from true sources. It is a set of skills (instructions the agent follows) plus a command-line tool, and it works with any coding agent. A custom Pi harness, with a Zed integration (ACP), is where it works best. The skills enforce one rule: every factual claim must point to your workspace, your Zotero library or the agent's memory, or it is cut or marked unverified. The CLI keeps the memory notes and searches your code and Zotero library.

Links
  • Private repository · public release upcoming
About Armitage

I love understanding things from first principles, grounded in true sources: books, documentation and papers. Armitage is how I take advantage of agentic workflows while keeping that habit: a tool tailored to my own use case, built to help me learn and develop Nodens and Nyar with every claim traceable to its source. It is built largely with AI coding agents, and agent tooling is outside my area of expertise (my background is graphics and numerical simulation), so treat it as a personal, experimental tool.

01 · Ask

One question

A single query searches its memory, your code and your papers together (armitage search).

02 · Match

Meaning + keywords

Embedding search (Ollama) finds passages by meaning; SQLite full-text search finds exact words.

03 · Rank

Best passages first

Both result lists are merged, then a reranking model (Qwen3) puts the most relevant first.

04 · Cite

Every claim sourced

Each factual statement carries an inline [^n] footnote to its source.

Where it looks

  • Memory (armitage memory): the agent's own notes, written and maintained by the agent as plain Markdown in an Obsidian vault: plans, decisions, concepts and your profile.
  • Papers and books (armitage zotero): your local Zotero 7+ library, read-only, with PDF text extraction and OCR for scanned pages.
  • Code (armitage code): an index of your repositories, shared across branches and worktrees. Looking up a symbol or where it is used needs no AI model.
  • Pi harness (armitage pi): the agent environment Armitage works best in, run in the terminal or in Zed's Agent Panel.

                                armitage
                                Agent
                                The citation gate. Before answering a factual question, it searches its memory, your code and your papers first and cites every claim inline. A claim it cannot trace to a source is cut or marked unverified.
                            

                            

                                armitage-init
                                Either
                                Starts or resumes a working session: recalls prior work, attaches the right project and plan, then routes to the next skill.
                            

                            

                                armitage-project
                                You
                                Keeps a project file for a bigger goal: its aims, ideas, open questions and decisions, with its plans listed automatically.
                            

                            

                                armitage-plan
                                You
                                Keeps a plan for one piece of work: goal, timeline, reasoning and references. Checkpoints progress so a later session can pick up where you left off.
                            

                            

                                armitage-research
                                You
                                Answers a hard question end to end: drafts a research plan, waits for your approval, reads each source, then writes a report citing the exact Zotero page behind every finding.
                            

                            

                                armitage-consolidate
                                You
                                Turns a reviewed research report into linked notes in the memory cache, plus an Obsidian canvas. Shows you the changes first and writes only after you approve.
                            

                            

                                armitage-tutor
                                You
                                Teaches you step by step instead of just writing the answer, grounded in your code, notes and papers.
                            

                            

                                armitage-swe
                                Agent
                                Before a big code change (more than 3 files or 80 lines, a new feature, a migration), writes one design plan and asks its open questions. It implements only after you approve.
                            

                            

                                armitage-issues
                                You
                                Writes, searches and triages GitHub issues as Armitage's own GitHub user. Nothing is sent until you approve it.
                            

                            

                                armitage-maintain
                                You
                                Beginner-friendly advice on versioning, git workflow, changelogs, releases and roadmaps, based on the repository's real state.
                            

                            

                                armitage-learn
                                Agent
                                Saves findings as citation-backed notes in the memory cache, so later sessions can recall what is true and what to do next.
                            

                            

                                armitage-decide
                                Agent
                                The moment you settle something ("never X", "keep Y"), records it with the reason and your own words, so no later session proposes the opposite.
                            

                            

                                armitage-user
                                Agent
                                Maintains your profile: preferences, corrections, goals and deadlines. Records a fact the turn you state it.
                            

                            

                                armitage-obsidian
                                Agent
                                Formats notes for Obsidian and builds tables, boards and canvas views of the memory when you ask for a map or dashboard.
                            

                            

                                armitage-help
                                You
                                Shows the quick-reference card for all the skills.
