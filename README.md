# EldritchCodex

Personal site for experiments in computer graphics, computational geometry, and engine design.

## Visual inspirations

The site mixes the look of an old printed reference with the warm glow of an instrument panel:

- **[MAINFRAME 1.0 by VKTRKRFT](https://www.behance.net/gallery/207791057/MAINFRAME-10-Premium)** on [Behance](https://www.behance.net/vktrkrft) — the vacuum-tube and phosphor glow: warm orange-amber light on rules and corner marks, faint scanlines, and top-lit panels with a warm edge bloom.
- **[Zed](https://zed.dev/)**: the agent-panel chrome recreated for the Armitage demo (`js/zed-deck.js`), with its slim title bar, role labels, tool-call list and footnote marks.
- **Brass astrolabes and star charts** — the rotating rings, degree ticks, and radial grid in the background (`js/bg-field.js`) and hero figure.
- **Lovecraftian archive and ledger printing** — numbered sections, two-column margin notes, hairline rules, and a bone-on-charcoal palette named after figures from the stories (*Nodens*, *Nyar*, *Armitage*).

## Typography

- [Fraunces](https://fonts.google.com/specimen/Fraunces) — display headings
- [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) — body text
- [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) — code, labels, and index marks
