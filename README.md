# EldritchCodex

Personal site for experiments in computer graphics, computational geometry, and engine design. The theme is inspired by Lovecraftian aesthetics.

Fonts used:
- Fraunces (headings)
- IBM Plex Sans (body)
- IBM Plex Mono (code)

To view locally, open `index.html` in a browser or serve with a simple HTTP server, for example:

```bash
python3 -m http.server
```
